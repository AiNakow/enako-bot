## 实现与配置位置

- `group_config` 基础插件按 `_adapter` → `group_config` 顺序加载，QQ 再加载指令面板。业务发现及全局选择沿用入口现有路径，初始化在加载业务插件前直接执行。
- 配置严格校验全部已知插件条目，包括未加载插件、非当前适配器条目和禁用群；初始化失败或选中插件加载失败使启动进程非零退出。
- 唯一运行预处理器按实际插件归属及父插件链执行判断。禁用时抛出 `IgnoredException`，保留原有规则、权限和阻断行为。
- QQ 使用现有 `group_id`，OneBot 使用数字群号的字符串形式。机器人私聊分别识别 C2C 和 OneBot 私聊；QQ 频道及频道私信沿用原行为。
- 启动快照使用只读映射和不可变值，重复初始化报错；生产代码没有重载入口。
- 单摄像头服务、忙碌锁、`PEOPLE_COUNTER_*`、全局 `INPUT_IMG_SIZE`、业务数据库格式、依赖及 Docker 卷保持既有设计。
